# Textual Spine — sources and loci

## Primary

### Mālinīvijayottaratantra (MV)
- Critical edition: Somadeva Vasudeva
- **MV 3/37–41ab** — Mālinī alphabet order (nādiphāntā: na → pha)
- **MV 4/114cd–118ab** — phonemes as tattva-body of Mālinī
- **MV 8/27–32** — base nyāsa procedure
- On volume: texts referenced via Tantrāloka apparatus + Hareesh notes

### Abhinavagupta
- **Tantrāloka 3.198–199** — śabdarāśi / Mātṛkā / Mālinī
- **Tantrāloka 4.91** — prāṇāyāma that torments the body is not to be practised
- **Tantrāloka 15/115cd–145** — three nyāsas: Mātṛkā (ordered), Mālinī (mixed), śabdarāśi (male assembly of 50 Bhairavas)
- **Tantrāloka 15/121–125** — Mālinī alphabet (from MV 3/37–41)
- **Tantrasāra** — varṇa-uccāra; phonemes from powers
- **Parātrīśikāvivaraṇa** — Mālinī order at madhyamā-vāc (PTv pp. 148–156 in Singh ed.)
- Editions on volume: Dyczkowski vols 1–11; Ishwar Ashram Trust Tantrasāra PDF; PTv Jaideva Singh metadata

## Key claims we encode

1. Mātṛkā = ordered phonemic universe (emission).
2. Mālinī = vowels and consonants interpenetrated = Śākta body.
3. Nyāsa installs glyph + sound + locus on the physical body.
4. Four levels of speech: vaikharī → madhyamā → paśyantī → parā.
5. Mantra/phoneme is not dead external sign; it is a mode of awareness (vimarśa).
