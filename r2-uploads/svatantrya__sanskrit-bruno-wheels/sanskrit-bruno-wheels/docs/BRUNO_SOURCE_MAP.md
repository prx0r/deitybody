# Bruno source map for the Sanskrit memory engine

This is a **functional source map**, not a claim that Bruno designed a Sanskrit pedagogy.

## 1. *De umbris idearum* + *Ars memoriae* (1582)
**Use:** the core rotating mnemonic encoder.

Historically relevant mechanics:
- fixed symbolic alphabets / sound chunks,
- agent + action + ensign + adstans/attribute + circumstance,
- concentric movable rings,
- composite animated images,
- placement into a larger internal space.

Modern scholarship summarized by the Warburg Institute notes that Rita Sturlese interpreted the large wheel as an aid for **foreign-word learning**, where phonetic constituents select images on concentric rings.

**Sanskrit adaptation:** exact chant/syllable memory and personal image composition.

## 2. *Explicatio triginta sigillorum* / *Ars reminiscendi* / *Sigillus sigillorum* (1583)
**Use:** choose an information geometry rather than putting everything into one palace.

Useful abstractions in this project:
- Campus = field/grid
- Caelum = spatial coordinate world
- Catena = sequence
- Arbor = hierarchy
- Scala = graded dimension
- Rota = combinatorial wheel
- Empiricus = test/record
- Interpres = translate between representations

These names are source-derived; the software meanings are **our computational abstractions**.

## 3. Llullian works: *De compendiosa architectura...*, *De lampade combinatoria lulliana*, *De specierum scrutinio*
**Use:** concept combination and systematic interrogation.

**Sanskrit adaptation:** manipulate roots, operators and grammatical relations as constrained combinatorial objects.

## 4. *Lampas triginta statuarum*
**Use:** stable personified conceptual forms.

**Sanskrit adaptation:** a dhātu may become a persistent imaginal “agent” whose identity survives many transformations. This is an analogy, not a historical Bruno→Pāṇini claim.

## 5. *De imaginum, signorum et idearum compositione* (1591)
**Use:** mature composition of images/signs/ideas and organized retrieval.

**Sanskrit adaptation:** compile a verse into multiple coordinated representations:
sound → morphology → relation → imaginal scene → retrieval route.

## 6. *De vinculis in genere*
**Use:** salience/binding layer.

**Sanskrit adaptation:** emotion, novelty, desire, personal relevance, rhythm, bodily sensation. These are used as **learner bindings**, not as linguistic facts.

## 7. *De magia* / *Theses de magia*
**Use:** historical theory of imagination, signs, spiritus and natural magic.

**Sanskrit adaptation:** none required for the learning engine. Keep this philosophical layer optional so the memory tool remains empirically testable.

## What we do NOT claim
- Bruno anticipated transformers or RoPE.
- Bruno knew Sanskrit or Pāṇini.
- Pāṇini's grammar is a Bruno wheel.
- Personal colours/body sensations are traditional Sanskrit correspondences.
- Random ring combinations produce valid Sanskrit.
